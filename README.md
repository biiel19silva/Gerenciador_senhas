🔐 MyPass — Gerenciador de Senhas em Python

📖 Sobre o projeto

O MyPass é um gerenciador de senhas simples desenvolvido em Python utilizando a biblioteca gráfica Tkinter.
O objetivo do projeto é permitir que o usuário:

- Gere senhas aleatórias seguras;
- Armazene credenciais de diferentes sites;
- Organize logins de maneira rápida e prática;
- Pratique conceitos fundamentais de Python e interfaces gráficas.

Este projeto foi desenvolvido com foco em aprendizado e prática de programação desktop com Python.

🚀 Funcionalidades

✅ Geração automática de senhas seguras
✅ Interface gráfica simples e intuitiva
✅ Salvamento local das credenciais em arquivo .txt
✅ Validação de campos obrigatórios
✅ Confirmação antes de salvar os dados
✅ Mensagens informativas utilizando messagebox

🛠️ Tecnologias utilizadas

- Python 3
- Tkinter
- Random

▶️ Como executar o projeto

1. Clone o repositório
git clone https://github.com/biiel19silva/Gerenciador_senhas.git
2. Acesse a pasta do projeto
cd Gerenciador_senhas
3. Execute o arquivo principal
python main.py
